# 3Dビジュアライザー分析・改善記録

分析日: 2026-09-05

## 対象と判断基準

最終DMX出力から灯体表示を評価する `src/shared/visualizer.ts`、描画を行う `src/renderer/components/visualizer/StageScene.tsx` と `sceneInstances.ts`、編集画面 `VisualizerApp.tsx` を確認した。照明コンソールとして、照射範囲・色・動きの確認精度、操作の安定性、170台での更新負荷を優先した。

RGB Fixtureと3D Fixtureの分離、Stage Layout専用Undo/Redoという既存ADRを維持した。作業開始時に存在したストロボ・選択操作・保存処理などの未コミット変更は保持している。本記録の「実装済み」は今回追加した変更を指す。

## 初回の再現・検証

回帰テスト `sceneProjection.test.ts` は実際の `updateVisualizerInstances` を呼び、GPUへ送るインスタンス行列と色を検証する。最初の実行で減光時の半径縮小、斜め照射の中心ずれ、無効交点を再現した。非表示行列は特異行列なので、テストではdecomposeではなく行列列ベクトルから直接スケールを読む。

検証結果:

- `npx vitest run`: 28ファイル、270テスト成功。新規7件は減光、斜め照射、40m高、床高0m・負値、水平・上向き照射を検証。
- 既存の170台CPU更新テスト: 30fps相当の33.3ms以内という条件に合格。これは行列・色の更新処理の測定であり、GPU描画や実機1080pのFPS保証ではない。
- `npx tsc -b`: 成功。
- `npx eslint src/renderer/components/visualizer`: 成功。
- `npx vite build`: 成功。500kBを超えるチャンクの警告は残る。
- 実画面: 既存の `visualizer-selection-test.html` をViteで開き、実際のVisualizerAppとStageSceneをブラウザ上で操作した。灯体の選択、perspective視点、設置X回転-40度、開始CHの解除、Dimmer 1→0.25を操作し、斜め照射と面積を維持した減光を画面で確認。
- DMX開始CHを戻し、テスト用Strobe DMXを10→11に変更。別時刻の画面で点灯・消灯の両フレームを確認。10へ戻して連続点灯も確認。
- 位置Zを7mへ変更し、照射が舞台奥を越える条件で床面外のマーカーが残らないことを確認。
- ブラウザに実行エラーなし。Three.Clockの非推奨警告あり。

ブラウザ検証はIPCをモックした既存ハーネスで行った。Electronのウィンドウ間通信、実機DMX、170台のGPUフレーム時間、電力消費は今回実測していない。性能向上率の数値は主張しない。

## 表現上の制限

この描画はルックの確認用であり、測光シミュレーターではない。照度の距離減衰、IES配光、露出、実機の発色、拡散反射は計算していない。加算合成も表示色空間上の近似である。

照射はビーム軸に基づく最初の受光面1枚への近似。ビーム端だけが障害物にかかる部分的な遮蔽、複数面にまたがる照射、透過する幕、回転した障害物や任意メッシュは未対応。遮蔽物の中に灯体を置く用途は想定していない。

楕円は円錐全体が受光面へ向く有限の交差だけを扱い、面に対して浅すぎる角度で楕円にならない交差は表示しない。空中ビームは軸の交点までの円錐なので、斜め照射の楕円外周と円錐端面は完全には一致しない。全体表示の範囲は舞台・遮蔽物・灯体であり、空中ビームの先端までは含まない。

ストロボ表示はモニターのリフレッシュレートと実際の描画速度に制約される。描画同期によって従来の固定30Hz制限は除いたが、実機の点滅タイミングを保証するものではない。
